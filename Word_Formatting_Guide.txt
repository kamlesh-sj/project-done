STEP 3: FORMATTING GUIDELINES
------------------------------
1. Font: Calibri or Arial, 12pt for body text
2. Headings: 
   - Chapter Headings: 16pt, Bold
   - Section Headings: 14pt, Bold
   - Sub-section Headings: 12pt, Bold
3. Line Spacing: 1.5 lines
4. Margins: 1 inch (2.54 cm) all sides
5. Left Margin: 1.25 inches for binding
6. Alignment: Justified
7. Page Numbers: Bottom center or bottom right

STEP 4: CODE FORMATTING
-----------------------
For all code samples in Appendix C and F:
1. Font: Courier New, 10pt
2. Background: Light gray (RGB: 245, 245, 245)
3. Border: Thin border around code blocks
4. Line spacing: Single

STEP 5: TABLE OF CONTENTS
-------------------------
1. Click where you want TOC (after Contents page)
2. Go to: References > Table of Contents
3. Choose Automatic Table
4. Update TOC after completing document

STEP 6: PAGE BREAKS
-------------------
Add page breaks before:
- Each new chapter
- Each major appendix section
- Title page, Acknowledgement, Synopsis
Use: Insert > Page Break (Ctrl+Enter)

STEP 7: REPLACE PLACEHOLDERS
-----------------------------
Find and replace all [BRACKETS] with your information:
- [STUDENT NAME]
- [REGISTRATION NUMBER]
- [Name of the Degree]
- [Guide Name]
- [HOD Name]
- [College/University Name]
- [Month - Year]

STEP 8: ADD COLLEGE LOGO
-------------------------
1. Click on [COLLEGE LOGO] placeholder on title page
2. Insert > Pictures
3. Select your college logo
4. Resize appropriately

STEP 9: FINAL REVIEW
--------------------
☐ Check all headings are properly styled
☐ Verify page numbers are correct
☐ Update Table of Contents
☐ Check all placeholders are replaced
☐ Verify code formatting
☐ Check for spelling and grammar
☐ Ensure consistent formatting throughout
☐ Verify page count is 90-100 pages
☐ Print preview to check layout
